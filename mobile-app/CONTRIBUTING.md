# Contributing to TalimZ

Thank you for your interest in contributing to TalimZ! This document provides guidelines for contributing to the project.

## Code of Conduct

Please be respectful and professional in all interactions. We're building an educational platform to help students learn better.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/talimz.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `flutter pub get`

## Development Guidelines

### Code Style
- Follow Dart/Flutter style guide
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions small and focused

### Commit Messages
Use clear, descriptive commit messages:
```
feat: add voice recognition for quiz answers
fix: resolve app crash on quiz completion
docs: update API integration guide
```

### Testing
- Test your changes on both Android and iOS
- Ensure AI features work with and without API keys
- Test edge cases and error scenarios

## Pull Request Process

1. Update documentation if needed
2. Ensure your code follows the style guide
3. Test thoroughly on different devices
4. Create a clear PR description explaining your changes
5. Link any related issues

## Areas for Contribution

- **New Subjects**: Add more educational subjects and topics
- **UI/UX**: Improve design and user experience
- **AI Features**: Enhance AI tutoring capabilities
- **Accessibility**: Make the app more accessible
- **Localization**: Add support for more languages
- **Performance**: Optimize app performance
- **Testing**: Add unit and integration tests

## Reporting Issues

When reporting bugs:
- Use a clear, descriptive title
- Provide steps to reproduce
- Include device/OS information
- Add screenshots if helpful

## Questions?

Feel free to open an issue for questions or discussions about contributing!
